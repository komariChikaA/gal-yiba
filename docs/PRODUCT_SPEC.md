# 产品范围（第一阶段）

## 核心体验

系统随机选择一部视觉小说作为答案。玩家搜索并提交作品后，系统按本局启用的比较项返回“一致 / 部分一致 / 不一致 / 未知”，数值项还返回答案更高或更低。玩家在有限次数或时间内猜中答案。

参考站提供了单人随机题、每日题、难度题池和固定的比较列。本项目保留清晰的推理反馈，但把比较列与题池标签改为房间规则，不把固定 13 列写死进游戏逻辑。

## 第一阶段范围

1. 在线房间：创建、房间码加入、准备、同步开始、提交猜测、结算、短时重连。
2. 房主配置：比较项、题池标签、剧透等级、是否只使用全年龄作品。
3. 数据：VNDB 与 Bangumi 的来源记录分开保存，通过可审核映射关联为站内作品。
4. 单人随机题、每日题与管理审核页保留为下一迭代。

## 暂不在第一阶段承诺

- 大规模随机匹配、全球排行榜和复杂反作弊。
- 直接复制或镜像第三方图片、简介、评论和用户数据。
- 自动认定所有 VNDB 与 Bangumi 同名条目为同一作品。
- 用外部 API 作为每次猜测的实时依赖。

## 比较项候选

| 键                 | 展示名         | 类型     | 初始判定                      |
| ------------------ | -------------- | -------- | ----------------------------- |
| `developer`        | 开发会社       | 集合     | 有交集为部分，集合相同为一致  |
| `publisher`        | 发行商         | 集合     | 有交集为部分，集合相同为一致  |
| `scenarioWriter`   | 脚本家         | 集合     | 有交集为部分，集合相同为一致  |
| `heroineHairColor` | 主要女角色发色 | 集合     | 有交集为部分，集合相同为一致  |
| `releaseYear`      | 首发年份       | 数值     | 相同为一致，否则给方向        |
| `playtime`         | 游戏时长       | 有序枚举 | 相同为一致，相邻可为部分      |
| `vndbRating`       | VNDB 综合评分  | 数值     | 误差 0.5 内为接近，并给方向   |
| `bangumiRating`    | Bangumi 评分   | 数值     | 误差 0.5 内为接近，并给方向   |
| `vndbVoteCount`    | VNDB 票数      | 数值     | 误差 10% 内为接近，并给方向   |
| `bangumiVoteCount` | Bangumi 票数   | 数值     | 误差 10% 内为接近，并给方向   |

## 当前实现决策（可在后续讨论中调整）

- “选择标签”同时支持选择比较列和筛选答案题池的作品标签。
- 多人首发采用所有人同题竞速；首位猜中者赢得本轮。
- 房间上限 8 人，默认 120 秒、8 次猜测、单轮决胜。
- 默认比较项为女主发色、两库独立评分与票数、年份、时长、动画化、全年龄、平台和标签。
- 平台比较将 Windows/Linux/macOS 等归并为 PC，并合并同一主机家族；Android、iOS、Web 仅在作品没有其他平台时保留，单部作品最多展示 4 个主要平台。
- 作品标签先按房间允许的剧透等级过滤，再按来源重要度选取前三个参与题池筛选与猜测比较。
- “女主发色”读取 VNDB 中该作品的非剧透 `primary` 女性角色；多名主要女角色保留颜色集合，不主观指定唯一第一女主。
- 搜索覆盖作品标题、别名和开发会社；模糊结果必须标明命中字段。
- 默认隐藏有剧透标签，但答案池包含所有年龄分类；房主可单独开启“只要全年龄游戏”。
- GitHub 仓库名、公开/私有、许可证以及正式域名仍待确认。
