# 比较颜色与方向规则

## 通用语义

- 绿色：值相同，或热度处于同一档。
- 黄色：存在可靠的接近、交集、同系列或父子品牌关系。
- 灰色：不匹配。
- 斜纹：任一侧没有足够数据，不能可靠判断。
- `+ / −`：答案的集合项数比猜测作品更多 / 更少。
- `↑ / ↓`：答案的数值或档位比猜测作品更高 / 更低。

## 各字段规则

| 字段                | 绿色                              | 黄色                               | 附加符号                         |
| ------------------- | --------------------------------- | ---------------------------------- | -------------------------------- |
| 作品名              | 同一作品                          | VNDB 官方关系表明为同系列          | 无                               |
| 开发会社            | 公司集合相同                      | 有公司交集，或审核过的父子品牌关系 | 公司数 `+ / −`；父子关系不带符号 |
| 发行商              | 集合相同                          | 有交集                             | 数量 `+ / −`                     |
| 脚本家              | VNDB 登记的脚本担当集合相同       | 有交集                             | 人数 `+ / −`                     |
| 女主发色            | 非剧透 primary 女角色发色集合相同 | 有交集                             | 发色数 `+ / −`                   |
| 首发年份            | 相同                              | 相差不超过 5 年                    | `↑ / ↓`                          |
| 游戏时长            | 同级                              | 相邻一个级别                       | `↑ / ↓`                          |
| VNDB / Bangumi 评分 | 相同                              | 相差不超过 1.0 分                  | `↑ / ↓`                          |
| VNDB / Bangumi 热度 | 同一票数档                        | 相邻一个票数档                     | `↑ / ↓`                          |
| 动画化              | 状态相同                          | 猜测作品为“已宣布、尚未播出”       | 无                               |
| 全年龄              | 状态相同                          | 不设黄色                           | 无                               |
| 平台                | 集合相同                          | 有主要平台交集                     | 答案有更多主要平台时为 `+`       |
| 标签                | 前三重要标签相同                  | 有部分交集                         | 无                               |
| 本地化语言          | 集合相同                          | 有交集                             | 数量 `+ / −`                     |

年份只读取 VNDB 官方 `complete` 发行版的最早日期，排除 `trial` 与 `partial`。年龄分类优先看成人内容证据；没有成人内容且存在 `0–15` 岁分级的正式版时归到全年龄侧。VNDB 的 `scenario` 担当不提供主次顺序，因此脚本家按该作品登记集合比较，不把它包装成数据库无法证明的“最主要脚本家”。公司父子关系不能从 VNDB API 自动取得，只允许使用有来源、可审核的关系表。

## 热度与评分分布快照

统计时间：2026-08-08。范围是生产题库中已启用且已验证映射的规范作品，不是 VNDB/Bangumi 全站分布。

| 来源    | 有评分作品 | 评分 P10 / P25 / P50 / P75 / P90 | 有票数作品 | 票数 P10 / P25 / P50 / P75 / P90 / P95    |
| ------- | ---------: | -------------------------------- | ---------: | ----------------------------------------- |
| VNDB    |      1,336 | 5.97 / 6.57 / 7.12 / 7.60 / 8.05 |      1,359 | 20 / 252 / 531 / 960 / 2,355 / 4,042      |
| Bangumi |          9 | 5.98 / 6.70 / 7.80 / 8.30 / 8.94 |          9 | 280 / 310 / 1,467 / 5,497 / 7,075 / 8,410 |

当前分档：

- VNDB：`0–49 / 50–249 / 250–499 / 500–999 / 1,000–2,499 / 2,500–3,999 / 4,000+`
- Bangumi：`0–299 / 300–999 / 1,000–2,999 / 3,000–5,999 / 6,000+`

VNDB 分档按当前题库分位数取整，兼顾低票作品和头部作品。Bangumi 目前只有 9 部完成跨库确认，样本仍小，所以先使用较宽的稳定档位；映射覆盖扩大后应重新统计，不能把这 9 部作品当作 Bangumi 全站代表。

评分统一保留来源的 1–10 分尺度；当前 VNDB 四分位距约为 1.03，使用“相差不超过 1.0 分”为黄色，既能表达接近，也不会把多数作品全部归为同档。Bangumi 继续使用同一可解释阈值，但不与 VNDB 分数混合。
